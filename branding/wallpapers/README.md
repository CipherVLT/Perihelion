# Wallpapers

Empty on purpose. Run `scripts/fetch-wallpapers.sh` to download the default
wallpapers (Kurzgesagt artwork via teowelton/Wallpapers) for a local build.
They are free for private, personal use only, so they are never committed
(see `.gitignore`) and ISOs built with them are for your own machines.

To ship wallpapers in a public build, put images you have the rights to
redistribute here (public domain or CC-licensed), write the default's file
name into `DEFAULT`, record their source and license in `NOTICE`, and
remove the ignore rule for that file.
